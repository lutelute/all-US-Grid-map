# all-US-Grid map

Interactive maps of the US transmission grid built automatically from OpenStreetMap
(the US counterpart of [All-Japan-Grid](https://lutelute.github.io/All-Japan-Grid/)).

- **US map / 全米地図:** https://lutelute.github.io/all-US-Grid-map/ — lines coloured by
  synchronous interconnection (Eastern / Western / ERCOT), seam cuts, DC ties
- **ERCOT snapshot / ERCOT 夏ピーク潮流:** https://lutelute.github.io/all-US-Grid-map/ercot.html —
  AC power flow on 2026-07-22 18:00 CDT (EIA-930 demand 91,075 MW)

Basemaps (satellite + labels, satellite, USGS NAIP, topographic, OpenStreetMap, light)
load live, so the imagery stays sharp down to individual towers.

## Disclaimer / 免責事項

> This data is generated **automatically by machine processing** of OpenStreetMap. It does
> **not** reflect official information from any utility, transmission operator or government
> agency, and may contain errors and omissions. The split into Eastern / Western / ERCOT uses
> balancing-authority polygons and a minimum edge cut, because OSM does not record
> normally-open points — seam placements are model decisions, not observed facts. Power-flow
> values on the ERCOT page use default line parameters, population-based demand and pro-rata
> dispatch: **they are model estimates, not measured flows. Use at your own risk.**
>
> 本データは OpenStreetMap を **機械的に自動処理** して生成したものです。電力会社・系統運用者・
> 政府機関の公式情報では **ありません**。誤り・欠落を含む可能性があります。東部・西部・ERCOT の
> 切り分けは、OSM に常時開路の情報がないため、BA ポリゴンと最小カットによるモデル上の判断です。
> ERCOT の潮流値は既定の線路定数・人口比例の需要・容量比の出力配分による **推定値で、実測ではありません**。
> **利用は自己責任** でお願いします。
